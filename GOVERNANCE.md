# Governance

nebwalk is currently maintainer-led. The maintainer has final responsibility
for releases, security response, API stability, and scientific claims.

Decisions should be recorded in issues or pull requests with alternatives,
evidence, compatibility impact, and validation results. Contributions are
evaluated on technical merit, reproducibility, scope, maintenance cost, and
alignment with the project's transparent NEB focus. No contributor receives
preferential technical treatment.

Trusted contributors may receive review or triage access after sustained,
constructive participation. Governance will be revised when multiple active
maintainers make consensus and succession rules necessary.
