# Support

Use GitHub Discussions for usage questions and the structured issue forms for
reproducible bugs or feature proposals. Community support is best-effort; no
response-time or computational-result warranty is provided.

Before requesting help, reduce the problem to a small script, confirm endpoint
and calculator settings, inspect the complete traceback, and run the latest
supported release. Include package versions and non-sensitive diagnostics.

Do not post credentials, proprietary structures, restricted pseudopotentials,
private cluster details, or large raw outputs. Security concerns follow
`SECURITY.md`.
